## ⚙️ Getting Started & Local Setup

### Prerequisites
- Flutter SDK 3.x
- Dart 3.x
- Android Studio / Xcode

### Installation & Run Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ahmedfawzyjr/ahmedfawzyjr.git
   cd ahmedfawzyjr
   ```

2. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

3. **Configure Environment**:
   ```bash
   cp .env.example .env
   ```

4. **Run Application**:
   ```bash
   flutter run
   ```
